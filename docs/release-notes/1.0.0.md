Magpie 1.0.0

- Activity timeline: open it from the bird icon in the left ribbon. Notes created and edited, captures, ticked or cancelled checkboxes and status changes, by day, week, month or year, with a 10-week heatmap, counts by type and a folder filter.
- Exact changes: each edit keeps its added and removed lines. Click "Show changes" to see them.
- Note history: a history icon next to the edit button in every note opens that note's full history.
- The log is stored as JSON lines per month and per device, so synced vaults do not clash. No network requests.
